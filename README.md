# Vibes TV

A streaming mobile application built with React Native and the TMDB API. Created to learn and practice React Native.

## Tech Stack

- TypeScript
- React Native (Expo)
- TMDB API
- NativeWind

## Features

- Browse movies and TV shows
- Search functionality

## Setup

1. Clone the repository: `git clone https://github.com/mohammadbilalmansuri/vibes-tv.git`
2. Go to the project directory: `cd vibes-tv`
3. Install dependencies: `npm install`
4. Create a TMDB account and generate an API Read Access Token.
5. Copy `.env.example` to `.env` and replace the placeholder with your token.
6. Start the development server: `npm start`
